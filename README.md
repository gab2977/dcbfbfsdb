# 🚥 Semáforo da Comunicação em Interfaces Web

Projeto desenvolvido em HTML5 e CSS3 focado em ensinar boas e más práticas de comunicação em interfaces web. O conteúdo é organizado através do conceito de semáforo (Verde, Amarelo e Vermelho), totalizando 15 cards interativos e acessíveis.

---

### ♿ 6 Práticas de Acessibilidade Aplicadas

1. **Informação Multissensorial (Uso além da cor):** As informações do semáforo não dependem unicamente da cor. Cada categoria utiliza **textos descritivos** ("Boas Práticas", "Atenção", "Evitar") e **símbolos/emojis** (🟢, 🟡, 🔴) para que usuários daltônicos compreendam o conteúdo facilmente.
2. **Alto Contraste de Textos:** Combinação de cores escuras sobre fundos claros, atendendo às recomendações WCAG para legibilidade de texto.
3. **Hierarquia Semântica:** Estruturação através de tags semânticas (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) e títulos em ordem lógica (`<h1>` e `<h2>`).
4. **Fonte Legível e Dimensionável:** Utilização de fontes do tipo *sans-serif* (`Arial, Helvetica`) com dimensionamento flexível e bom espaçamento entre linhas (`line-height: 1.6`).
5. **Atributos para Leitores de Tela:** Uso de atributos ARIA como `aria-label`, `aria-hidden="true"` para ícones decorativos e `aria-labelledby` para identificar seções corretamente.
6. **Layout Responsivo e Adaptável:** Design com CSS Grid flexível e media queries (`@media`), garantindo que o conteúdo seja legível em celulares e monitores de diferentes tamanhos sem perda de dados.

---

### 🚀 Publicação no GitHub Pages

1. Crie um novo repositório público no GitHub com o nome `semaforo-da-comunicacao`.
2. Adicione os arquivos `index.html`, `style.css` e `README.md` ao repositório.
3. Acesse as **Settings** (Configurações) do repositório.
4. No menu lateral, selecione a opção **Pages**.
5. Na seção **Build and deployment**, escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde alguns instantes até que o link da página publicada fique disponível.
